## 📊 Dataset

This project uses **BCI Competition IV – Dataset 2a**, a benchmark EEG dataset for 4-class cued motor imagery classification.

### Dataset Overview
- **Classes:** Left Hand, Right Hand, Both Feet, Tongue
- **EEG Channels:** 22
- **EOG Channels:** 3
- **Sampling Rate:** 250 Hz
- **Subjects:** 9
- **Sessions:** 2 per subject
- **Training Files:** `A0XT.gdf`
- **Testing Files:** `A0XE.gdf`
